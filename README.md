# 법조치 통합관리 도구 (Legal Collections Manager)

여신 사후관리의 **법적절차 운영**을 한 화면에서 판단·관리하기 위해 만든 데스크톱 도구입니다.
사건 조회 → 상태 판단 → 송달·보정 관리 → 서류 작성 → 기일·기한 → 경매·배당 → 회수 분석까지 이어집니다.

> 이 저장소에는 **예시 데이터만** 들어 있습니다. 사건번호·이름·계좌 등은 모두 가짜 값이며, 실무 데이터와 회사 자료는 포함하지 않았습니다.

---

## 왜 만들었나

| 기존 방식의 문제 | 이 도구의 접근 |
|---|---|
| 사건마다 법원 사이트를 열어 진행상황을 수기로 옮겨 적음 | 사건 대장 기준으로 반자동 일괄 조회, 결과를 사건별로 누적 저장 |
| 보정명령·송달불능·확정을 사람이 읽고 다음 절차를 판단 | **규칙 기반 상태 분류**로 「확인할 것」 목록과 기한을 자동 생성 |
| 송달·보정·회생·경매·배당 정보가 여러 엑셀에 흩어짐 | 채무자·법조치·송달·회생·경매·배당을 하나의 사건 키로 연결 |
| 법조치 비용 대비 회수 효과를 보기 어려움 | 원자료를 넣으면 회수 경로(직접·연계)·압류 판단·시효 임박을 분석 |

## 주요 기능

| 영역 | 기능 |
|---|---|
| 사건 조회 | 법원·사건번호·당사자로 조회, 엑셀 대량 조회(머리글·칸 이름 자동 인식), 중단 후 이어서 조회 |
| 확인할 것 | 보정명령·송달불능·선고·확정·기일, 경매 새 문건·매각기일을 모아 처리 여부 관리 |
| 법조치 콘솔 | 보정 기한 임박, 회생·파산 중지, 이번 주 작성 서류, 오늘 할 일을 한 화면에 |
| 송달·보정 | 기한 관리, 「예상」 기한은 추정임을 표시 |
| 회생·파산 | 등재·폐지 관리, 채무자 원장과 연결해 집행 재개 대상 확인 |
| 경매·배당 | 경매 사건 조회·문건/송달 추적, 배당기일 관리, 소송 사건과 자동 연결 |
| 서류 작성 | 양식 기반 법조치 서류 생성, 사건번호 표기 형식 자동 맞춤 |
| 회수 분석 | 원자료 칸·값 맞추기 → 자료 점검표 → 압류 판단·회수 경로·연별 통계 |

## 설계 원칙

- **규칙은 데이터로**: 상태 분류 규칙을 설정값으로 두어, 절차·문구가 바뀌어도 코드 수정 없이 반영 (`app/core/rules.py`)
- **추정은 숨기지 않음**: 송달일이 없는 자료는 추정값을 쓰되 화면과 기준표에 「추정」이라고 표시
- **자료 기준일로 계산**: 오늘 날짜가 아닌 자료 기준일로 시효 임박 등을 계산해 오래된 자료에서도 숫자가 틀어지지 않게 함
- **개인정보 최소 보관**: 주민번호 13자리가 들어오면 그 칸 전체를 버리고 알림, 앞자리만 연령대·성별로 변환
- **같은 계산 경로**: 예시 자료도 실제 양식과 같은 조립 함수를 거치게 해, 실데이터 없이도 계산 로직을 검증
- **넣기 전 점검**: 빠진 필수 칸, 못 읽은 날짜·금액, 키 불일치를 점검표로 먼저 보여 줌

## 구조

```
app/
  main.py            시작 파일 (앱 창 / 브라우저 모드)
  bridge_*.py        화면 ↔ 기능 연결
  core/              조회·규칙·법조치·경매·배당·회수분석 로직
  ui/                화면 (HTML·CSS·JS)
  data/              법원 목록 등 공개 기본 정보
tests/               기능 점검 (법원 사이트에 접속하지 않음, 가짜 결과 사용)
tools/               빌드·매뉴얼·예시 양식 생성
packaging/           배포용 안내문·사용법
launcher/            Windows 실행 파일 (Go)
```

## 실행

```bash
pip install pywebview openpyxl xlrd pypdfium2 pillow truststore
python app/main.py            # 앱 창 모드
python app/main.py --browser  # 브라우저 모드
python app/main.py --demo     # 법원 사이트 대신 꾸며 낸 결과로 화면 점검
```

## 참고

- 법원 사이트 조회는 사용자가 보안문자를 직접 입력하는 **반자동** 방식입니다. 로봇 탐지가 걸리면 멈추고 안내합니다.
- 업무 요건 정의, 판단 규칙 설계, 검증은 직접 했고, 구현은 AI 개발 도구의 도움을 받았습니다.
